Jogo adivinhe
O jogo consiste em o computador sortear um número aleatório e o jogador ter que descobri-lo

para executar escreva python adivinhe.py

O nível 1 você tem 3 chances e o computador da o número máximo de 10
O nível 2 você tem 5 chances e o computador da o número máximo de 100
O nível 3 você tem 10 chances e o computador da o número máximo de 1000

foi usado o pílar de váriavel para decidir o número aleatório

operador para retirar 1 da váriavel opcao

entrada para o jogador falar o nível

saída para mostra se o jogador errou ou acertou

repetição foi o return para voltar se ainda tivesse chances

condição foi o if, elif e else para ver se o jogador acertou

sub rotina foi usado para continuar jogando caso ainda tenha chances com o while
